# 01. SCM and Why Git is Popular

## What is SCM?

SCM stands for **Source Code Management**.

SCM is used to manage and track changes made to source code.

It helps development teams to:

- Store source code
- Track changes
- Maintain different versions
- Maintain code history
- Identify changes made by developers
- Work with multiple developers

## Why Do We Need SCM?

In real-time projects, multiple developers work on the same application.

Without SCM, it becomes difficult to:

- Track who changed the code
- Maintain previous versions
- Work with multiple developers
- Recover previous code
- Manage code changes

SCM solves these problems.

## What is Git?

Git is a **Version Control System (VCS)** and **Source Code Management (SCM)** tool.

Git helps developers manage and track changes in source code.

## Why is Git So Popular?

Git became very popular because it provides:

- Easy version control
- Fast performance
- Branching and merging
- Complete change history
- Collaboration between developers
- Distributed version control
- Integration with platforms like GitHub

## Git in Real-Time Projects

A typical development flow can be:

```text
Developer
    ↓
   Git
    ↓
GitHub / GitLab / Bitbucket
    ↓
Development Team
```

## Key Point

> Git is a popular SCM tool used to manage, track, and collaborate on source code.
