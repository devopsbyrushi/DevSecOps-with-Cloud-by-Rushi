# DevSecOps with Cloud – By Rushi

## Section 02: Git and GitHub

### 03. Creating a GitHub Account

---

## 1. What is GitHub?

GitHub is a cloud-based platform used to store Git repositories and collaborate with other developers.

We will use GitHub throughout this course to:

- Store source code
- Create repositories
- Push code
- Collaborate with developers
- Manage project versions

---

## 2. Open GitHub

Open the GitHub website:

https://github.com/

Click **Sign up** to create a new account.

**Screenshot:** GitHub Home Page

---

## 3. Enter Your Email

Enter your email address.

Click **Continue**.

**Screenshot:** Email Registration

---

## 4. Create a Password

Enter a strong password for your GitHub account.

GitHub currently requires either:

- At least 15 characters

**OR**

- At least 8 characters with a number and a lowercase letter.

Click **Continue**.

**Screenshot:** Password Creation

---

## 5. Choose a Username

Enter the username you want to use on GitHub.

Example:

```text
devopsbyrushi
```

GitHub usernames can contain letters and numbers, with single hyphens allowed between characters.

Choose a professional username because your GitHub profile can be used as part of your professional portfolio.

**Screenshot:** Username Selection

---

## 6. Select Country or Region

Select your country or region.

Example:

```text
India
```

**Screenshot:** Country/Region Selection

---

## 7. Email Preferences

GitHub may ask whether you want to receive product updates and announcements.

Choose the option based on your preference.

**Screenshot:** Email Preferences

---

## 8. Verify Your Account

GitHub will ask you to complete an account verification step.

Complete the verification shown on the screen.

**Screenshot:** Account Verification

---

## 9. Create Your Account

After completing the required information and verification, click:

**Create account**

Your GitHub account will be created.

**Screenshot:** Create Account

---

## 10. Verify Your Email Address

Check your email inbox for the GitHub verification email.

Open the email and complete the verification process.

A verified email is important because GitHub requires a verified email address for some basic activities, including creating a repository.

**Screenshot:** Email Verification

---

## 11. Login to GitHub

After completing the registration, go to:

https://github.com/login

Enter your GitHub username or email address and password.

You can now access your GitHub account.

**Screenshot:** GitHub Login

---

## 12. Check Your GitHub Profile

After logging in, open your profile and check:

- Username
- Profile name
- Profile picture
- Repositories
- Contribution activity

Keep your GitHub profile professional because we will use it throughout the DevOps learning journey.

---

## Practice

Create your GitHub account and make sure:

- [ ] GitHub account is created
- [ ] Email is verified
- [ ] Username is selected
- [ ] You can login successfully
- [ ] GitHub profile is accessible

---

## Key Point

> GitHub provides a cloud platform where we can store Git repositories and collaborate with other developers.
